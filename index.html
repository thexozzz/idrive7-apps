Co ma aplikacja w THEiPlay

  • Zwykła strona WWW w silniku Chrome (piaskownica, internet, HTML/CSS/JS, WebAudio).
  • Dotyk ekranu i kursor z gładzika kontrolera ("mouse": "yes"), przewijanie dwoma palcami, gesty wstecz / dalej, pokrętło = kliknięcie.
  • Dźwięk przez głośniki auta (G21 Audio).
  • Klawiatura THEiPlay dla pól tekstowych.
  • Pełny ekran (requestFullscreen): cały ekran środkowy 1920×720.
  • Zegary i HUD: THEiPlay > Aplikacje > Ustawienia > Zegary / HUD pokazuje tam obraz aplikacji.
  • Dane auta, tylko odczyt: sygnały SOME/IP, które aplikacja zgłosi w theiplay.json (karta Sygnały pokazuje wszystkie).
  • Odczyty diagnostyczne sterowników ("uds"): pytanie do sterownika, tylko usługi odczytu 22 i 01 (karta Sterowniki).

Czego nie ma

  • Zapisu do auta: żadnego ustawiania pól ani wywołań.
  • Zapisu, kodowania, kasowania błędów ani testów elementów w sterownikach.
  • Sygnałów o osobie i miejscu: VIN, pozycja, cele, telefon, kontakty, profile.
  • Mikrofonu, Bluetooth, USB, pobierania plików, rozszerzeń Chrome, DRM.

theiplay.json

{
  "name": "Nazwa kafelka",
  "start": "index.html",
  "mouse": "yes",
  "car": [
    "de.bmw.infotainment.vehicle.Vehicle2.statusCarSpeed2",
    "de.bmw.infotainment.KombiIF.*",
    "*"
  ],
  "uds": ["12", "18"]
}

Odczyt sygnału

var app = location.pathname.split('/')[1];
fetch('/_car/' + app + '/list')            // { ok, ifaces: { interfejs: [pola] } }
fetch('/_car/' + app + '/get?i=' + interfejs + '&n=' + pole)
  .then(r => r.json())                   // { ok, value } albo { ok:false, err }
// pytanie do sterownika: e = adres, s = 22 albo 01, d = identyfikator (hex)
fetch('/_car/' + app + '/uds?e=12&s=01&d=05')   // { ok, data: "hex" } albo { ok:false, err }
