Runtime libraries and fonts for the browser engine on the head unit.

The engine itself (Google's chrome-headless-shell, the build engine/manifest.json names) is NOT in
this tool: the head unit downloads it from Google's Chrome for Testing storage and keeps it only
when every file has the SHA-256 the manifest lists. It is Google's program under Google's terms.

The engine is a dynamically linked program. The head unit has an older C library and lacks most of
what the engine links to, so this tool carries those libraries and the engine uses ONLY these (its
ELF interpreter is lib/ld-linux-x86-64.so.2, its search path is lib/): nothing of the head unit's
/lib or /usr/lib is replaced or changed.

The files below are the unmodified binaries of these Ubuntu 24.04.5 LTS packages (x86-64), copied from an
installed system. Corresponding sources: http://archive.ubuntu.com/ubuntu (noble, noble-updates,
noble-security), package name and version as listed.
